    Key terms
    Parked request
    A request for an actor that has no worker yet.
    Park budget (just "budget" in this lab)
    The longest the router keeps a parked request waiting. The clock starts when the router first tries to resume the actor.
    Parking off
    The sibling setting requestParking.max caps how many requests can be parked at once (default 1024). max: 0 turns parking off: a request that finds no free worker gets 429 right away, with no wait.

    Parking handles seconds

    When workers free up within the budget, parked requests are served instead of rejected. Scenario 1 against "parking off" is the whole difference.

    The HPA handles minutes

    Parking cannot create a worker. Under sustained load only more workers help, and the HPA adds them from the busy-worker count.

    Size one to the other

    Set the park budget to how long scale-up takes on your nodes. Then a burst that starts on two workers is served while the pool grows.
